Production-Grade Features

Every feature built for real-world reliability and clean architecture

⚡

Full URL Audit

Returns status code, response time (ms), page title, HTTPS status, content-type, server, response size (bytes), redirect count and final URL.

🧩

Strict Validation

Zod v4 schema rejects ftp://, javascript:, bare text, empty strings — only valid HTTP/HTTPS URLs pass through.

⚡

Smart Caching

NodeCache with configurable TTL (default 5 min). Same URL returns instantly from cache. Response includes "cached": true.

⏱

Timeout Protection

Requests exceeding 5 seconds are terminated immediately with a structured TIMEOUT error response.

🛡

Rate Limiting

express-rate-limit enforces 100 req/min per IP. Returns structured 429 RATE_LIMIT_EXCEEDED on breach.

🔀

Concurrency Control

p-limit gates max 50 simultaneous audits. Overflow returns 503 SERVER_BUSY immediately.

📋

Structured Logging

Pino logger with unique REQ-XXXXXX IDs per request. JSON logs in production, pretty in dev.

🔒

Security-First

Helmet.js headers, CORS, gzip compression, multi-stage Docker (non-root user). GitHub Actions CI on every push.

✅

23 Tests Passing

Jest + Supertest with 23 test cases covering success, cache hits, timeouts, invalid URLs, error formats, and request IDs.
