⚡ Page Pulse API

Production-grade URL Audit Service. Send any website URL and get back a comprehensive health report — status codes, response time, page title, HTTPS status, server info, redirect counts, and more.

🔗
Base URL
localhost:3000
🔑
Auth Required
None (Public)
📦
Format
JSON
⏱
Timeout
5 seconds
🛡
Rate Limit
100 / min
⚡
Cache TTL
5 minutes
💡 No API Key required. All endpoints are public. Just send a JSON body with a "url" field.

🔑 Authentication

Page Pulse is a fully public API — no authentication or API keys are required. Simply send requests to the endpoints below.

ℹ️ Every response includes an X-Request-ID header for debugging (e.g. REQ-A1B2C3D4E5F6).
POST
/audit
Audit a URL — returns full health report including status, response time, title, HTTPS, server, size, and redirects.
▼
Request Body (JSON)
FieldTypeRequiredDescription
url string Required A valid HTTP or HTTPS URL (e.g. https://google.com)
Request Example
HTTP 
POST /audit HTTP/1.1
Content-Type: application/json

{
  "url": "https://google.com"
}

⚠️ Error Codes

        
All errors follow the same structure: { success: false, error: { code, message }, requestId }

        

          

            
HTTPCodeCause

            
              
400INVALID_URLNot a valid HTTP/HTTPS URL (ftp://, empty, bare string)

              
429RATE_LIMIT_EXCEEDEDMore than 100 requests/minute from same IP

              
502UNREACHABLEDNS resolution failed or connection refused

              
503SERVER_BUSY50 concurrent audits limit reached

              
504TIMEOUTWebsite didn't respond within 5000ms

            
          

        


        


        
        
🛡 Rate Limiting

        
Rate limiting is applied per IP address. Exceeding the limit returns a structured 429 error response.

        

          
Max Requests
100 per window

          
Window Duration
60 seconds

          
Scope
Per IP address

        

        

          ⚠️ Rate limit headers are included in every response: RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset.
